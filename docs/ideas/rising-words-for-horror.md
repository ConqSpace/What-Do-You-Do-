# 아이디어: 공포 장면용 "어절 떠오르기"

말풍선 등장 애니메이션 시안 중 C(어절이 빈자리에서 아래→위로 떠오르며 나타남)는 일반 서술에는 쓰지 않기로 했다(지금은 C'' "흐린 글자 밝히기"를 쓴다). 그런데 C가 불쾌했던 이유가 공포에서는 그대로 장점이 된다.

## 왜 불쾌했나 = 왜 무서울 수 있나

- **눈이 끌려간다.** 새로 나타나고 움직이는 것에는 시선이 저절로 간다. 어절마다 이 반사가 당겨져서 "글이 눈에 꽂히는" 느낌이 든다.
- **박자를 빼앗긴다.** 다음 어절이 나올 때까지 읽을 수 없고, 천천히 읽으려 해도 계속 밀려온다. 읽는 사람이 통제권을 잃는다.
- **글줄이 흔들린다.** 어절이 떠오르는 동안 밑선이 움직여 초점이 자리를 못 잡는다.
- **앞을 미리 볼 수 없다.** 다음 어절 자리가 비어 있다가 갑자기 생긴다. 매번 작은 기습이다.

평소에는 피로지만, 공포에서는 "통제할 수 없는 것이 머릿속으로 들어온다"는 감각이 된다.

## 쓸 만한 곳

- 크툴루의 부름: 이성 판정 직전·직후의 서술, 인간이 아닌 존재의 목소리, 꿈이나 환청.
- 어느 룰이든: 마스터가 "이 대사는 섬뜩하게"라고 표시한 NPC 대사, 귓속말로 온 불길한 것.
- 아껴 쓸 것. 한 세션에 몇 번만 나와야 효과가 있다. 계속 쓰면 그냥 읽기 힘든 화면이 된다.

## 만든다면

- `public/app.js`의 `reveal()`에 방식을 하나 더 둔다: 처음 상태를 `opacity: 0; transform: translateY(5px)`로, 켜질 때 `opacity: 1; transform: none` (전환 0.3초). 시안의 박자는 한 글자당 약 32~34ms, 어절 사이 +60ms.
- 어떤 메시지에 쓸지는 서버가 표시한다. 예: 메시지에 `dread: true` (CoC 이성 판정이 걸린 차례의 서술, 마스터가 NPC 대사에 붙인 표시 등).
- 더 불안하게: 박자를 일정하지 않게(가끔 멈칫), 아주 가끔 어절 하나가 늦게 떠오르게.
- "동작 줄이기"와 "기다리지 않기"에서는 끈다. 빨리 감기로 즉시 끝낼 수 있어야 한다.
